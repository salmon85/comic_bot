# Backgrounds

Put your cell background PNG files in this directory.

Every `.png` file here can be used as the background of the comic cells:

```
!setbackground <file name without .png>
```

Backgrounds are scaled to cover the whole cell and cropped from the centre, so
the characters and speech bubbles stay on top of them. Only moderators, the
broadcaster and the channel owner can change the background.

Use `!backgrounds` to list the available files and `!background` to show the
current one.
